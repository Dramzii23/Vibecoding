Lista completa de las cuentas que vas a necesitar durante el curso. Casi todas tienen versión gratis suficiente para llegar a Demo Day, con dos excepciones: **OpenAI** (necesitas cargar $5–10 USD de saldo) y tu **editor con IA**. Para el editor puedes usar <Term id="cursor">Cursor</Term> (Pro, ~$20 USD/mes; el plan gratis se acaba rápido y no alcanza para trabajar el proyecto completo) o **Claude Code** (requiere la versión de pago de Claude — ver [Claude Code paso a paso](/docs/configuracion/claude-code)). Presupuéstalo: el curso dura 9 semanas.

| Servicio | Para qué | Cuándo lo creas | Versión gratis |
|---|---|---|---|
| <BrandIcon brand="github" /> [GitHub](https://github.com) | Repo y deploy | Día 1 | Sí, ilimitado para repos públicos y privados |
| <BrandIcon brand="vercel" /> [Vercel](https://vercel.com) | Hosting + analytics — ver [Vercel Analytics](/docs/configuracion/vercel-analytics) | Día 1 | Sí, Hobby — suficiente |
| <BrandIcon brand="supabase" /> [Supabase](https://supabase.com) | DB + Auth — ver [Supabase paso a paso](/docs/setup/supabase) | Día 1 | Sí, 2 proyectos gratis |
| <BrandIcon brand="openai" /> [OpenAI](https://platform.openai.com) | IA | Sem 0 (se usa desde Sem 3) | No — necesitas cargar $5–10 |
| <BrandIcon brand="resend" /> [Resend](https://resend.com) | Email | Cuando la necesites (opcional) | Sí, 3000 emails/mes |
| <BrandIcon brand="googlecloud" /> [Google Cloud](https://console.cloud.google.com) | OAuth Google — ver [Login con Google (paso a paso)](/docs/configuracion/google-oauth) | Sem 2 | Sí (sólo para credenciales OAuth) |
| <BrandIcon brand="paypal" /> [PayPal](https://paypal.me) | Pagos (opcional) — ver [PayPal](/docs/configuracion/paypal) | Sesión de pagos | Sí — el trámite Business tarda, empiézalo antes |
| <BrandIcon brand="cursor" /> [Cursor](https://cursor.com) | IDE | Día 1 | Plan gratis muy limitado; Pro ~$20/mes (alternativa: Claude Code, requiere Claude de pago) |
| <BrandIcon brand="claude" /> [Claude](https://claude.ai) | Claude Code, alternativa a Cursor (opcional) — ver [Claude Code paso a paso](/docs/configuracion/claude-code) | Si lo prefieres a Cursor | No — requiere la versión de pago de Claude (Pro, ~$20/mes) |

<Callout type="info" title="Carga $10 en OpenAI desde Semana 0">
Para evitar atorones después, crea tu cuenta de OpenAI y carga $5–10 USD desde la **Semana 0** (lo usarás a partir de la Semana 3). Un MVP del curso completo consume ~$5–10 con gpt-4o-mini. Si te preocupa el gasto, ponle un tope: [Costos y capas gratis](/docs/setup/costos).
</Callout>

Con tus cuentas creadas (<Term id="github">GitHub</Term>, <Term id="vercel">Vercel</Term> y <Term id="supabase">Supabase</Term> como mínimo), sigue con [Supabase paso a paso](/docs/setup/supabase) para dejar tu proyecto listo.
