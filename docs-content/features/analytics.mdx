</Callout>

Vibecoding usa **Vercel Web Analytics**: el paquete `@vercel/analytics` ya está instalado y el componente `<Analytics />` viene montado en `web/app/layout.js`. No hay toggle ni variables de entorno — solo falta **habilitarlo en el dashboard de Vercel** (pestaña Analytics de tu proyecto → Enable). El paso a paso está en [Vercel Analytics](/docs/configuracion/vercel-analytics).

Qué te da out of the box: visitantes, páginas vistas, páginas más visitadas y de dónde llega la gente (referrers). Solo mide tu app **publicada** en Vercel, no `localhost`.

Si además quieres registrar eventos propios (ej. `signup`, clic en el CTA), el mismo paquete trae la función `track()`:

```js
import { track } from "@vercel/analytics"

track("signup")
```
